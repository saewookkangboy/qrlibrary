# 커맨드 마케팅 QR 라이브러리 — 실무 UX 개선 설계

**날짜:** 2026-09-03  
**접근:** 접근 1 — 실무 워크플로 재편 (책 구조 유지 + 실행·진입·품질 UX)  
**대상 파일:** `index.html` (단일 페이지)

---

## 1. 목표·범위

### 목표
책 QR 부록 정체성은 유지한 채, 마케터가 “오늘 이 카드로 AI에 바로 실행”까지 끊기지 않게 한다.

### 범위 (이번 라운드)
- 단일 `index.html` 안에서 UX·상호작용 개선
- 기존 32개 카드 데이터·해시 링크(`#02-rgctor` 등)·localStorage 키 호환 유지
- 외부 AI 딥링크·계정 연동·서버 저장은 제외

### 성공 기준
1. 필드 작성 후 **한 번 복사**로 AI에 붙일 완성 지시문이 나온다
2. “지금 할 일”로 핵심 카드에 30초 안에 진입한다
3. 예시·관련 카드·미작성 경고로 빈칸 제출·고립 사용을 줄인다

### 비범위
- ChatGPT/Claude 딥링크, 서버 저장, 계정
- 카드 본문(프롬프트 문장) 대량 재작성
- 디자인 시스템 전면 리브랜드
- 새 프레임워크/빌드 분리

---

## 2. 화면 구성·정보구조

기존 레이아웃(사이드바 + 작업 영역)을 유지하고, 진입·실행·다음 행동만 보강한다.

### 사이드바
1. **상황별 바로가기** (상단, 고정 6개)
   - 오늘 VOC · R-G-C-T-O-R · 콘텐츠 캘린더 · 광고 실험 · CRM · 주간 리포트
2. 기존 **섹션 내비** (시작하기 → … → 업데이트 로그) + 검색
3. 진도 바 (기존 유지)
4. (여유 시) 완료 카드 **전체 MD 일괄 다운로드**

### 카드 작업 영역 (세로 흐름)

| 순서 | 패널 | 역할 |
|------|------|------|
| 01 | 이렇게 완성합니다 | 기존 3단계 + **관련 카드** 링크 |
| 02 | 내 업무로 작성하기 | 필드 + **예시 채우기** / **작성 초기화** |
| 03 | Agent에게 실행 | **완성 지시문 미리보기** + **완성본 복사** (핵심 CTA) · 템플릿만 복사는 보조 |
| 04 | 최종 검수 | 체크리스트 · MD 다운로드 · 완료 · **다음 추천 카드** |

### 보조
- 책 연결 정보 유지
- 미작성 필드가 있으면 복사 버튼 옆 경고: “N개 칸이 비어 있음 · 그래도 복사”
- 해시·SEO·모바일 메뉴 동작은 기존과 동일

---

## 3. 핵심 기능 동작

### A. 완성 지시문 합성

복사·미리보기·MD 다운로드 본문은 동일 빌더로 생성한다.

```
[실습] {제목}
[연결] {Part} · {Chapter}
[목표] {outcome}

## 내 입력
### {필드명}
{작성값 또는 [작성 필요]}

## 실행 지시
{기존 prompt}
(플레이스홀더 {{역할}} 등이 있으면 해당 필드값으로 치환)

## 검수 기준
- {체크 항목들}
```

| 액션 | 동작 |
|------|------|
| 완성본 복사 | 위 전체 클립보드 복사 |
| 템플릿만 복사 | 기존처럼 `prompt`만 복사 |
| MD 내려받기 | 위 합성과 동일 형식의 `.md` 파일 |

- 빈 칸이 있어도 복사는 허용
- UI에 “N개 미작성” 경고 표시
- R-G-C-T-O-R 등 `{{…}}` 플레이스홀더는 필드 라벨 매핑으로 치환  
  - 예: `{{역할}}` ↔ Role, `{{목표}}` ↔ Goal 등 (카드별 명시 맵 또는 라벨 키워드 매칭)

### B. 예시 채우기 / 초기화

- 카드별 `examples` 객체(필드 라벨 → 샘플 문장)를 데이터에 추가
- **예시 채우기**: 빈 칸만 채움(이미 쓴 값은 덮지 않음)
- **예시로 덮어쓰기**: 확인 후 전체 교체 (버튼 또는 보조 액션)
- **작성 초기화**: 현재 카드 `values`만 삭제(완료·체크는 유지)
- 예시 톤: 가상의 B2B SaaS 마케팅 시나리오로 통일, UI에 “예시” 명시

### C. 관련 카드 · 다음 추천

데이터에 `related: [id, …]` (2~3개)와 고정 시나리오 맵을 둔다.

| 바로가기 | 대표 카드 → 이어서 |
|----------|-------------------|
| 오늘 VOC | `03-voc` → `03-campaign` → `04-copy` |
| R-G-C-T-O-R | `02-rgctor` → `02-canvas` → `06-cards` |
| 콘텐츠 캘린더 | `04-calendar` → `04-copy` → `04-qa` |
| 광고 실험 | `05-adtest` → `05-creative` → `05-log` |
| CRM | `05-crm` → `01-hitl` → `05-report` |
| 주간 리포트 | `05-report` → `05-meeting` → `05-log` |

- 카드 하단 **다음 추천**: `related` 중 첫 미완료 카드(없으면 `related[0]`)
- 시나리오 바로가기는 JS 상수로 두고, 카드 JSON과 분리

### D. 저장·내보내기

- localStorage 키 `command-marketing-library-html` 및 스키마 호환 유지  
  (`values` / `checked` / `complete`)
- MD 다운로드 본문은 합성 형식과 맞춤
- (여유 시) 완료 카드만 모아 일괄 MD 다운로드

---

## 4. 데이터 변경

`#library-data` JSON의 각 resource에 선택 필드 추가:

```json
{
  "examples": {
    "현재 역할": "콘텐츠·퍼포먼스·CRM을 함께 맡는 1인 마케터",
    "반복 업무": "매주 광고 성과를 요약해 보고한다"
  },
  "related": ["03-campaign", "04-copy"]
}
```

기존 필드(`steps`, `fields`, `prompt`, `checks`, `outcome` 등)는 변경하지 않는다.

---

## 5. 구현 순서

1. 합성 지시문 빌더 + 완성본 복사/미리보기 + MD 형식 정렬
2. 예시 채우기·초기화·미작성 경고
3. 상황별 바로가기 + related/다음 추천 UI
4. 32개 카드에 `examples`·`related` 채우기
5. (여유 시) 완료 카드 일괄 MD 다운로드
6. 모바일·해시·SEO 회귀 확인

---

## 6. 리스크·대응

| 리스크 | 대응 |
|--------|------|
| localStorage 깨짐 | 기존 키·스키마 유지, 새 필드는 데이터 전용 |
| 예시가 실무와 어긋남 | B2B SaaS 가상 시나리오 통일, “예시” 명시 |
| 미리보기가 길어짐 | `<details>` 접기 또는 스크롤 영역 |
| 플레이스홀더 매핑 누락 | 치환 실패 시 원문 유지 + `[작성 필요]` |

---

## 7. 테스트 체크리스트

- [ ] 필드 작성 → 완성본 복사 → 클립보드에 입력·지시·검수가 모두 포함
- [ ] 빈 칸만 있을 때 미작성 경고 + 그래도 복사 가능
- [ ] R-G-C-T-O-R `{{…}}` 치환
- [ ] 예시 채우기(빈 칸만) / 덮어쓰기 / 초기화
- [ ] 바로가기 6개 → 올바른 카드·해시
- [ ] related·다음 추천 클릭 → 해당 카드 이동
- [ ] 기존 해시 URL·진도·검색·모바일 메뉴 정상
- [ ] 기존 localStorage 데이터로 필드·완료 상태 복원
